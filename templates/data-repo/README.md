# Quotes data

The price list, customers and quotes of one Organization, read and written by
its Quotes App through [repository-db](https://github.com/Lazurio/repository-db).
This repository is checked out on branch `v3` as the `db/` directory of the
Quotes Module.

| Path | Holds |
| --- | --- |
| `data/settings/settings.yaml` | the settings: VAT rates, the number format, the Organization's details on a quote, the e-mail text |
| `data/categories/<id>.yaml` | one category of the price list per file |
| `data/items/<code>.yaml` | one item of the price list with its price history |
| `data/customers/<id>.yaml` | one customer |
| `data/quotes/<number>-v<version>.yaml` | one version of a quote |
| `schemas/<collection>.schema.json` | the schemas, generated by the Quotes App; never edited here |
| `scripts/validate.ts` | the validator repository-db runs before every publish |

Every document is the envelope of repository-db (`schemaVersion`, `id`,
`record`). Amounts are whole haléře (minor units): `139000` is 1 390,00 Kč.

A change is published from the Quotes App ("Koncept a publikování" / "Draft &
publish") or as a pull request to `v3`. Validate locally with
`bun scripts/validate.ts`.
