# Quotes data: rules for agents

- This repository holds the Organization's own price list, customers and
  quotes. It is private to the Organization; never copy its records into
  another Organization or into the public Quotes template.
- Write records through the Quotes App or its command line (`bun run quotes`
  in the Module's `app/v3`, see the Module's skills): every write is a draft
  that a person reviews and publishes in the App. Publishing is a Publication:
  only on the user's instruction. A pull request to `v3` is the other way.
- Never send a quote to a customer from here. Sending is the person's step.
- Never commit anything under `generated/` or `.repository-db/`.
- `schemas/` is generated by the Quotes App (`bun run schema:export` in its
  `app/v3`). Change the Zod schema there and copy the result here in the same
  release; never edit a schema here by hand.
- Run `bun scripts/validate.ts` before you open a pull request.
